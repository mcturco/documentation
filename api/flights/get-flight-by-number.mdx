Returns a single scheduled flight given its unique flight number. Use this endpoint to look up specific flight details — for example, to validate a flight number before creating a booking.

**Endpoint**

```
GET https://api.kong-air.com/flights/{flightNumber}
```

## Request

### Headers

<ParamField header="X-API-Key" type="string">
  Your Kong Air API key. Required if not using Bearer authentication.
</ParamField>

<ParamField header="Authorization" type="string">
  Bearer JWT token. Required if not using API key authentication. Format: `Bearer <token>`
</ParamField>

### Path parameters

<ParamField path="flightNumber" type="string" required>
  The unique flight number to look up. Example: `KD924`
</ParamField>

## Response

Returns a single Flight object.

<ResponseField name="number" type="string" required>
  The flight number
</ResponseField>

<ResponseField name="route_id" type="string" required>
  Route identifier in `ORIGIN-DEST` format, e.g. `LHR-SFO`
</ResponseField>

<ResponseField name="scheduled_departure" type="string (ISO 8601 datetime)" required>
  Scheduled departure time in UTC
</ResponseField>

<ResponseField name="scheduled_arrival" type="string (ISO 8601 datetime)" required>
  Scheduled arrival time in UTC
</ResponseField>

## Examples

```bash
curl -s \
  -H "X-API-Key: $KONG_AIR_API_KEY" \
  https://api.kong-air.com/flights/KD924
```

**200 OK Response**

```json
{
  "number": "KD924",
  "route_id": "LHR-SFO",
  "scheduled_departure": "2024-03-20T09:12:28Z",
  "scheduled_arrival": "2024-03-20T19:12:28Z"
}
```

## Error codes

| Code | Description |
|------|-------------|
| `401 Unauthorized` | Missing or invalid authentication credentials |
| `404 Not Found` | No flight exists with the given flight number |
| `500 Internal Server Error` | Service is temporarily unavailable |
