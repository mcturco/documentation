---

Returns all scheduled Kong Air flights for a given day. If no `date` parameter is provided, the endpoint returns flights for the current day. Use this endpoint to build flight search and listing features.

**Endpoint**

```
GET https://api.kong-air.com/flights
```

## Request

### Headers

<ParamField header="X-API-Key" type="string">
  Your Kong Air API key. Required if not using Bearer authentication.
</ParamField>

<ParamField header="Authorization" type="string">
  Bearer JWT token. Required if not using API key authentication. Format: `Bearer <token>`
</ParamField>

### Query parameters

<ParamField query="date" type="string">
  Filter flights by date. Format: `YYYY-MM-DD`. Defaults to the current day if omitted.
</ParamField>

## Response

Returns a JSON array of Flight objects.

<ResponseField name="number" type="string" required>
  Unique flight number, e.g. `KD924`
</ResponseField>

<ResponseField name="route_id" type="string" required>
  Route identifier in `ORIGIN-DEST` format, e.g. `LHR-SFO`
</ResponseField>

<ResponseField name="scheduled_departure" type="string (ISO 8601 datetime)" required>
  Scheduled departure time in UTC
</ResponseField>

<ResponseField name="scheduled_arrival" type="string (ISO 8601 datetime)" required>
  Scheduled arrival time in UTC
</ResponseField>

## Examples

<CodeGroup>

```bash Get today's flights
curl -s \
  -H "X-API-Key: $KONG_AIR_API_KEY" \
  https://api.kong-air.com/flights
```

```bash Filter by date
curl -s \
  -H "X-API-Key: $KONG_AIR_API_KEY" \
  "https://api.kong-air.com/flights?date=2024-03-20"
```

</CodeGroup>

**200 OK Response**

```json
[
  {
    "number": "KD924",
    "route_id": "LHR-SFO",
    "scheduled_departure": "2024-03-20T09:12:28Z",
    "scheduled_arrival": "2024-03-20T19:12:28Z"
  },
  {
    "number": "KD925",
    "route_id": "SFO-LHR",
    "scheduled_departure": "2024-03-21T09:12:28Z",
    "scheduled_arrival": "2024-03-21T19:12:28Z"
  }
]
```

## Error codes

| Code | Description |
|------|-------------|
| `401 Unauthorized` | Missing or invalid authentication credentials |
| `500 Internal Server Error` | Service is temporarily unavailable |
